Architecture

Comment est construit le plugin thematique, le plus développé du dépôt. Les autres plugins « site » suivent les mêmes principes.

Squelettes : un fonctionnement en popups ajax

Le site n’enchaîne pas des pages classiques. squelettes/layout.html (canevas, #CACHE{0}) charge une page « sommaire », puis le contenu (article, rubrique, formulaire) s’ouvre dans une popup chargée en ajax (mode=ajax-detail) par les contrôleurs JS (squelettes/js/controleurs.js, squelettes/js/main.js).

  • squelettes/noisettes/ : blocs inclus, souvent en #CACHE{0} parce qu’ils dépendent de la session ou d’un cookie (c’est indiqué en tête de chaque fichier concerné).
  • squelettes/modeles/ : mini-squelettes appelés par #MODELE{}, par exemple pour résoudre un logo ou une icône.

Deux forums coexistent. L’ancien (noisettes/ajax/article-forum-detail.html, noisettes/inc/forum.html) et forumv2 (noisettes/inc/forumv2/*, câblé depuis noisettes/sidebar/onglet_commentaires.html). C’est forumv2 qui est en service sur les pages article : vérifiez quel chemin est exécuté avant de modifier l’un des deux.

Données JSON de la page d’accueil

La frise (timeline) et les menus de la page d’accueil sont construits en JavaScript à partir de squelettes qui produisent du JSON, appelés par spip.php?page=json&mode=…. Le paramètre mode choisit le fond inclus dans squelettes/json/ :

modeDonnées
demarrageAssemble les autres fonds en une seule réponse pour le chargement initial.
projetInformations du projet.
consignesConsignes de l’année et leurs réponses.
classesClasses de l’année (numéro, couleur, icône).
articlesArticles d’agenda ou de salle des profs (&type=blogs ou evenements).
ajaxAccès direct aux blocs ajax.

Ces fonds sont en #CACHE{0} : ils dépendent de l’année scolaire choisie par cookie, et SPIP ne différencie pas son cache selon les cookies. Un cache, même court, servirait la mauvaise année à d’autres visiteurs.

Résolutions en PHP plutôt qu’en boucles non cachées

Les résolutions répétées (type de contenu d’une rubrique, d’un article ou d’un auteur, couleur et numéro de classe, rôle en session, rubrique par mot-clé) sont des fonctions de thematique_fonctions.php avec un cache mémoire statique par requête, appelées comme filtres SPIP :

function thematique_xxx($id) {
	static $cache = [];
	if (array_key_exists($id, $cache)) {
		return $cache[$id];
	}
	// une seule requête SQL par valeur distincte et par requête HTTP
	return $cache[$id] = sql_getfetsel(...);
}
[(#ID_RUBRIQUE|thematique_type_objet_rubrique)]

Exemples : thematique_type_objet_rubrique, _article, _auteur, classe_numero, classe_icone, classe_id_rubrique_forum, thematique_donner_role, thematique_id_rubrique_a_mot. Une résolution répétée dans un #MODELE{} ou une boucle imbriquée non cachée gagne à passer sur ce modèle.

Rôle de session

thematique_donner_role($id_auteur) renvoie prof, intervenant, admin, eleve ou null. Il est calculé dans le pipeline preparer_fichier_session (thematique_preparer_fichier_session), déclenché à chaque écriture du fichier de session, et exposé par #SESSION{role}.

Ce n’est pas fait dans preparer_visiteur_session : ce pipeline ne s’exécute que pour /ecrire ou le formulaire de connexion natif, jamais pour la connexion SSO qu’utilisent presque tous les comptes. Ne recalculez pas le rôle ailleurs.

fond_consigne_pour_role() et fond_reponse_pour_role() choisissent le fond de la sidebar selon ce rôle.

Année scolaire

La constante _ANNEE_SCOLAIRE (définie dans plugins/projets/ccn/ccn_options.php) structure presque tout le contenu : les rubriques racines sont organisées par année, et thematique_pre_boucle() (pipeline pre_boucle) filtre automatiquement les boucles ARTICLES et SYNDIC_ARTICLES sur la période de l’année active, sauf avec le critère {tout} ou depuis /ecrire.

FonctionValeur
thematique_annee_scolaire()Année sélectionnée par le visiteur (cookie ou paramètre GET).
thematique_annee_scolaire_reelle()Année calendaire réelle, indépendante de la sélection.

Des classes, missions ou pictos absents sur un environnement ? Vérifiez d’abord la présence et le titre de la rubrique racine de l’année active : c’est plus souvent un problème de données qu’un bug de squelette.

Connexion SSO (ENT laclasse.com)

inc/thematique_cioidc.php et thematique_cioidc_userinfo() (dans thematique_pipelines.php) gèrent la connexion OpenID Connect via l’ENT : à partir des attributs ENT (ENTClassesGroupes, ENTPersonProfils, ENTGroupesLibres…), ils retrouvent ou créent l’auteur SPIP, fixent son statut (prof, élève, webmestre) et le lient à ses rubriques de classe.

Le détail (attributs, tableau de décision, choix des classes, diagnostic) est sur la page Connexion et comptes.

Le plugin CIOIDC n’est activé que si SPIP_PLUGINS_CIOIDC=true (voir variables d’environnement).

Traductions

Tout texte visible passe par un item de langue déclaré dans lang/thematique_fr.php :

  • squelettes : <:thematique:cle:> ;
  • PHP : _T('thematique:cle') ;
  • JavaScript : objet CCN.lang, construit dans squelettes/noisettes/timeline.html (seul pont PHP → JS pour les traductions).

Cette règle est vérifiée par les lints CI.

Tâches de fond

Enregistrées toutes les 24 h via le pipeline taches_generales_cron :

  • genie/thematique_rentree_annee.php : crée la structure de la nouvelle année scolaire ;
  • genie/thematique_rentree_poubelle.php : à la rentrée, passe les comptes non-webmestres à la poubelle pour forcer leur recréation via l’ENT avec les données de la nouvelle année.
