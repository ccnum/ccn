Classes Culturelles Numériques

Monorepo SPIP qui fait tourner les sites CCN de l’ENT laclasse.com : des classes, des intervenants culturels et un projet commun sur une année scolaire.

Une installation comprend un cœur SPIP (ecrire/, prive/, squelettes-dist/, plugins-dist/), installé par le Dockerfile et non versionné, et des plugins maison dans plugins/projets/. C’est dans ces plugins que se fait le développement ; le reste est le framework SPIP, à ne modifier qu’en cas de besoin explicite.

Un code, plusieurs sites

Le site est multisite : chaque instance (sites/<nom>/) partage le même code mais a sa propre base de données et sa propre configuration. Le plugin activé dépend de la variable SPIP_VERSION_SITE (voir Déploiement).

Démarrage rapide

Avec ddev (développement local)

ddev start     # web, db, phpmyadmin
ddev launch    # ouvre https://ccn.ddev.site

Les instances locales sont exposées par nom d’hôte : ccn-fictions, ccn-ontourne, ccn-petitfablab, edifice-digitalyceen (suffixe .ddev.site).

Avec Docker

cp .env.example .env   # puis renseigner les valeurs
docker-compose up
